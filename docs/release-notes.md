## 让你的 Agent，共享同一个大脑

v0.2.1 修复 ima 省略长笔记标题造成的查找和候选重试问题。云端索引和候选使用短标题定位，再校验从正文读回的数据。

### 下载哪个文件

- **ima-agent-memory-workbuddy-v0.2.1.zip**：WorkBuddy 技能包，ZIP 根目录直接包含 SKILL.md，内含运行代码、空白模板和虚构示例。
- **INSTALL.md**：安装步骤、环境要求与当前限制。
- **SHA256SUMS**：技能 ZIP 和安装说明的 SHA-256 校验值。

需要 Node.js 22+；无需 npm install。本地模式不需要账号或网络。
连接 ima 时，由使用者配置自己的官方 ima-skill、凭证与知识库。
发行附件不包含维护者的真实记忆、账号配置、聊天记录或同步状态。

### 功能与接入

- 维护机使用 Ed25519 签名 `CURRENT`，其他设备固定发布者公钥并校验正文。遇到旧版本或暂时无法确认最新版本时，索引标记已验证的回退版本。
- 正式索引只发布入口、偏好、项目摘要及决策。MCP 日常检索跳过候选，维护者用 CLI 独立审阅。
- 单条格式错误和内容冲突记录进入隔离清单。云端提交可传 `request_id`，重试复用该请求在本机已记录的笔记。
- 发布时使用同一份读取内容生成正文和索引哈希，消除两个读取阶段之间发生修改造成的版本错配。

本发行由 GitHub Actions 从所指向的源码构建，在发布附件前运行测试和隐私检查。
通用协议和离线测试不代表所有客户端已经完成端到端验收；尚未经过 SkillHub 平台审核。

### 升级云端空间

保留技能目录外的原记忆目录。维护机先运行 `sync --apply`。接收端更换技能版本后，
从维护机取得 `trust-export` 输出，用 `trust-import --file` 固定公钥，再重启 MCP。
已经在 v0.2.0 固定公钥的设备沿用原公钥。维护机的首次 v0.2.1 同步会发出短标题索引，既有文档可复用。
本地模式可使用原目录直接升级。接入权限由 IMA 账号和操作系统决定，旧云端快照仍可按原权限访问。

WorkBuddy 导入时请选择专用技能附件，GitHub 自动生成的 Source code ZIP 为源码归档。
