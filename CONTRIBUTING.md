# Contributing

Use Node 22+ and run `node --test` and `node scripts/check-privacy.cjs`.
No dependency installation is required. Keep new tests synthetic and offline;
never use a developer's real memory home or knowledge base as a fixture.

Discuss behavior changes with a concrete example. Preserve source attribution,
candidate/canonical separation, project boundaries, local-first defaults and
resumable sync. Do not add implicit chat-history import or automatic cloud upload.
Keep platform-specific paths and personal data out of examples and commit metadata.

The official ima-skill is an external dependency with its own terms. Do not copy
its source into this repository. Contributions are made under this project's MIT
license. Follow the GitHub repository's ordinary pull request workflow.
